# Add a minimal browser interface for the ClaimPilot demo

## Why

The assessment requires a working user surface, not only API endpoints or Postman requests.

## Acceptance criteria

- [ ] User can sign in and see their role.
- [ ] User can ask a policy question and inspect the response.
- [ ] User can load and create claims.
- [ ] User can run an adjudication and see live SSE events.
- [ ] User can cancel the client stream.
- [ ] Supervisor can view the pending review queue.

## Pull request checklist

- Include a screenshot or short recording in the PR description.
- Add a self-review comment for request cancellation behaviour.
