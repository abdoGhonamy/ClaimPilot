# Create the instructor teaching pack and demo plan

## Why

This is an instructor assessment; the project must be explainable and usable as a trainee lab.

## Acceptance criteria

- [ ] Create a 15–25 slide deck based on ClaimPilot.
- [ ] Add hands-on lab instructions, expected outputs, three stretch challenges, and answer key.
- [ ] Add learning outcomes and assessment map.
- [ ] Add common trainee mistakes and corrections.
- [ ] Add product-demo and teaching-video recording plans.

## Pull request checklist

- Verify the deck opens and renders correctly.
- Add a self-review comment explaining one exercise and its expected evidence.
