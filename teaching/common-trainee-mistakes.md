# Common Trainee Mistakes

1. Treating a plausible answer as evidence: require a citation and source excerpt.
2. Letting the LLM calculate money: keep limits and deductibles in deterministic code.
3. Retrieving the latest policy: filter by incident date before reasoning.
4. Treating approval as a UI button: enforce authority on the server.
5. Treating prompt injection as only a user-input problem: test malicious retrieved text too.
